# Sales Jarvis hackathon demo

Browser sales workspace with eight fictional SPIN buyers. Typed requests prepare source-linked follow-up drafts and internal handoffs, saved on the current device.

Live demo: https://deft-cuchufli-1359c0.netlify.app/

```sh
npm run build
npm test
npm start
```

Guided offline demo. Live AI/voice, external outreach and shared CRM sync are not implemented in this web version. No real customer data, provider keys, personal accounts or private runtime are included. See DEPLOY.md and the font/photo licenses.
